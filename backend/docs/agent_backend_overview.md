# Agent Backend Overview

## 목적

이 문서는 FastAPI 백엔드 전체 흐름을 설명한다.

## 전체 서비스 흐름

사용자 회원가입  
→ 로그인  
→ JWT 발급  
→ 사용자 프로필 입력  
→ 분석 세션 생성  
→ 얼굴 사진 업로드  
→ 이미지 저장  
→ 모델 추론  
→ 부위별 피부 결과 저장  
→ 부위별 리포트 생성  
→ 부위별 화장품 추천 생성  
→ 사용자 화면용 응답 반환

## 입력 방식

### 운영 서비스 입력

운영 서비스의 기본 입력은 사용자 얼굴 이미지이다.

사용자가 핸드폰으로 직접 촬영하거나 갤러리에서 선택한 사진을 업로드한다.

### 개발/테스트 입력

AI-Hub 라벨링 JSON은 개발/테스트용으로만 사용한다.

모델이 아직 연결되지 않았을 때 다음을 검증하기 위해 사용한다.

- DB 저장 흐름
- 분석 결과 저장
- 추천 로직
- 리포트 응답 구조

## 저장 단위와 화면 단위

DB에는 세부 분석 결과를 저장한다.

예:

- 왼쪽 볼 - 모공
- 오른쪽 볼 - 모공
- 눈가 - 주름
- 입술 - 건조
- 턱 - 처짐

사용자 화면에는 부위별로 묶어서 보여준다.

예:

- 볼: 모공 케어 추천
- 눈가: 주름 개선 추천
- 입술: 보습 추천
- 턱: 탄력 관리 추천

실제 사용자 화면에는 DB row를 그대로 노출하지 않고, `report_service.py`에서 부위별 리포트 형태로 가공하여 반환한다.
