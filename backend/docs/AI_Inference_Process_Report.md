# AI 피부 분석 서버 작동 원리 보고서

본 보고서는 `multivalue_ai_server.py`를 중심으로, AI가 어떻게 사용자의 사진에서 얼굴 부위를 찾고 피부 상태를 분석하는지 그 흐름을 상세히 설명합니다.

---

## 1. 개요 (Introduction)

본 AI 서버는 사용자가 촬영한 얼굴 사진 한 장을 입력받아, **얼굴의 주요 8개 부위(이마, 눈가, 볼 등)를 탐지**하고, 각 부위별로 **주름, 색소 침착, 모공, 수분도 등의 피부 상태를 정밀하게 판정**하는 시스템입니다. 최신 딥러닝 기술인 **YOLO**와 **DINOv3**를 결합하여 빠르고 정확한 분석 결과를 제공합니다.

---

## 2. 전체 분석 흐름 (Workflow)

전체 과정은 크게 **이미지 입력 -> 부위 탐지(YOLO) -> 피부 분석(DINOv3) -> 결과 구성**의 4단계로 진행됩니다.

### 2.1. 이미지 입력 (Image Input)
사용자가 앱이나 웹을 통해 얼굴 사진을 업로드하면, 서버(FastAPI)가 이 이미지를 받아 분석 준비를 합니다. 이미지는 AI가 이해하기 쉬운 RGB 형태의 디지털 데이터로 변환됩니다.

### 2.2. 얼굴 부위 찾기 (부위 탐지 - YOLO v8)
가장 먼저 하는 일은 사진 속 어디에 이마가 있고, 어디에 눈이 있는지 위치를 찾는 것입니다.

*   **YOLO(You Only Look Once) 모델**: 이미지 전체를 한 번에 훑어 사물의 위치를 찾아내는 매우 빠른 AI 모델입니다.
*   **탐지 대상**: 총 8개 부위 (이마, 미간, 왼쪽 눈, 오른쪽 눈, 왼쪽 볼, 오른쪽 볼, 입술, 턱)를 찾습니다.
*   **결과**: 각 부위의 위치를 나타내는 사각형 좌표(Bounding Box)와 AI가 확신하는 정도(Confidence Score)를 얻습니다.

### 2.3. 피부 상태 정밀 분석 (피부 판정 - DINOv3 Multi-task)
위치 정보를 바탕으로 실제 피부 상태가 어떤지 점수를 매기는 단계입니다.

*   **이미지 크롭 및 여백 추가(BBox Expansion)**: YOLO가 찾은 위치를 그대로 자르는 것이 아니라, **상하좌우로 약 15%의 여백**을 더해 자릅니다. 이는 분석 대상 부위뿐만 아니라 주변부의 흐름까지 AI가 함께 파악하여 더 정확하게 판단하기 위함입니다.
*   **이미지 규격화 (Resize)**: 잘라낸 다양한 크기의 부위 이미지들을 AI가 처리하기 가장 좋은 크기인 **448x448 픽셀**로 동일하게 맞춥니다.
*   **좌우 반전 교차 분석 (TTA: Test Time Augmentation)**: 원본 사진뿐만 아니라 **좌우를 뒤집은 사진까지 동시에 분석**한 뒤, 그 결과를 종합합니다. 이는 마치 의사가 환자를 여러 각도에서 살펴보는 것과 같아 분석의 신뢰도를 높여줍니다.
*   **DINOv3 백본(Backbone)**: 이미지의 아주 미세한 특징(질감, 색상 변화 등)을 잡아내는 고성능 시각 AI 엔진입니다.
*   **멀티태스크(Multi-task) 학습**: "이 사진은 주름이 몇 점인가요?"와 "색소 침착은 몇 개인가요?"라는 질문에 대해 하나의 AI가 동시에 대답합니다. 이를 통해 분석 속도를 획기적으로 높였습니다.
*   **판정 항목**:
    *   **등급(Grade)**: 주름, 모공, 색소 등의 심각도를 0~N 등급으로 판정.
    *   **측정값(Measurement)**: 수분도(%), 탄력도 수치 등을 소수점 단위로 정밀 계산.
    *   **개수(Count)**: 여드름이나 색소 침착의 개수를 직접 카운팅.

### 2.4. 결과 데이터 구성 (Response Building)
AI가 내놓은 수많은 계산 결과들을 사용자가 보기 편한 형식으로 정리합니다.

*   **표준화**: 분석된 데이터들을 미리 약속된 형식(JSON)에 맞춰 배치합니다.
*   **예외 처리**: 만약 조명이 어둡거나 각도가 안 좋아 AI가 부위를 찾지 못했다면, 에러 대신 `0`이나 `null` 값을 넣어 시스템이 안정적으로 작동하게 합니다.

## 3. 프로세스 플로우차트 (Flowchart)

```mermaid
graph TD
    A[이미지 업로드] --> B{서버 수신}
    B --> C[YOLO: 얼굴 부위 탐지]
    
    subgraph "부위 탐지 (Detection)"
    C --> D1[이마 위치]
    C --> D2[눈가 위치]
    C --> D3[볼/턱 위치]
    end
    
    D1 & D2 & D3 --> E[이미지 자르기 & 전처리]
    
    subgraph "정밀 분석 (Inference)"
    E --> F[DINOv3: 특징 추출]
    F --> G1[주름/모공 등급 판정]
    F --> G2[수분/탄력 측정값 계산]
    F --> G3[트러블 개수 카운팅]
    end
    
    G1 & G2 & G3 --> H[결과 데이터 통합]
    H --> I[최종 결과 반환 (JSON)]
```

## 4. 핵심 기술 요약

| 기술명 | 역할 | 비유 |
| :--- | :--- | :--- |
| **YOLO** | 얼굴 부위 탐지 | 사진 속에서 눈, 코, 입의 **위치**를 찾는 '검색 대장' |
| **DINOv3** | 이미지 특징 추출 | 피부의 결, 모공 하나하나를 **세밀하게 관찰**하는 '현미경' |
| **Multi-task Head** | 종합 판정 | 여러 상태를 **동시에 진단**하는 '전문의' |

---

## 5. 상세 데이터 매핑 정보 (Data Mapping)

AI가 분석하는 각 부위별 상세 항목은 다음과 같습니다.

| 분석 부위 (Facepart) | 등급 판정 (Grade) | 정밀 측정 및 개수 (Measurement/Count) |
| :--- | :--- | :--- |
| **전체 (Full Face)** | - | 색소 침착 개수, 여드름 개수 |
| **이마 (Forehead)** | 이마 색소, 이마 주름 | 수분도, 탄력도(R0~R9, Q0~Q3) |
| **미간 (Glabella)** | 미간 주름 | - |
| **눈가 (Eye)** | 눈가 주름 | 눈가 주름 정밀 수치 (Ra, Rmax, Rz 등) |
| **볼 (Cheek)** | 볼 모공, 볼 색소 | 수분도, 탄력도, 모공 개수 |
| **입술 (Lips)** | 입술 건조도 | - |
| **턱 (Chin)** | 턱 처짐(Sagging) | 탄력도 |
